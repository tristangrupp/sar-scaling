How to read this

  • Sentinel-1 SM is not a background mode. ESA tasks it mostly over small islands, some coasts and emergencies, so most inland sites will show X-band only.
  • Capella and Umbra fly single-pol (HH or VV). A pair counts only when the S1 scene carries the same co-pol channel.
  • "IW ±6 d" counts co-pol Sentinel-1 IW scenes within six days of the best SM scene: the low-resolution input for an IW → X-band model you can then check against SM.
  • S1 incidence is the scene-center value from the CDSE catalog; per-pixel incidence across the footprint can differ by a few degrees.
